# Gestionale Triage Pronto Soccorso

Applicazione da console in C++ per la registrazione dei pazienti e il triage.

## Funzionalità
- Registrazione paziente (anagrafica, orario di arrivo)
- Questionario sui sintomi, con calcolo del punteggio e assegnazione del codice triage
- Sintomi specifici per area clinica (cardiaco, respiratorio, neurologico, ecc.)
- Lista pazienti

## Compilazione
g++ nomefile.cpp -o triage
